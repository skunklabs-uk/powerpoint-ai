# Data Pipeline Blueprint

Cartella progetto per la presentazione sulla blueprint di una data pipeline riusabile su piu' iniziative: Kiron CDG, Internal CDG e ProSIGNAL.

## Struttura

| Path | Contenuto |
|---|---|
| `drafts/` | Intake, inventario fonti, repo-to-deck brief, storyline e creative handoff |
| `prompts/` | Prompt usati per recupero materiale, analisi repository o generazione deck |
| `source-materials/` | Materiali sorgente raccolti da repo, documenti, deck e file di progetto |
| `visual-references/` | Reference visive specifiche della presentazione |
| `generated-assets/` | Asset o script generati per questa presentazione |
| `attempts/` | Tentativi, export intermedi e output non finali |

## Obiettivo Iniziale

Preparare una presentazione executive/technical blueprint che spieghi come costruire una data pipeline riusabile, partendo dalle evidenze dei progetti CDG e rendendo esplicito cosa puo' essere generalizzato per Kiron CDG, Internal CDG e ProSIGNAL.

## Stato

- Versione PowerPoint di riferimento: `Data pipeline blueprint v5.pptx`.
- Recap C-level: `Data pipeline comparison C-level v2.xlsx`.
- Preview per le slide: i cinque file `generated-assets/Slide recap *.png`.
- Le fonti, i materiali di progetto e le note di confronto restano disponibili per mantenere il grounding della versione corrente.
- Versioni precedenti, export intermedi, workbook dettagliato e candidate visuali sono stati spostati in `attempts/archive/`.

## Archivio

`attempts/archive/` conserva i materiali non necessari alla versione corrente senza cancellarli:

- `legacy-decks/`: v2, v3 e v4 del PowerPoint;
- `legacy-exports/`: PDF e immagini di export precedenti;
- `legacy-workbooks/`: workbook dettagliato superato dal recap C-level;
- `legacy-recaps/`: varianti precedenti delle preview;
- `legacy-generators/`: generatori e render intermedi delle versioni precedenti;
- `dashboard-showcase-candidates/`: immagini candidate non utilizzate nella slide attuale.
